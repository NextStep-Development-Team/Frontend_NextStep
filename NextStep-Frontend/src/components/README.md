# Componentes Compartidos (UI)

Componentes puramente visuales y reutilizables en toda la aplicación.

## Estructura

- `common/`: Botones, Inputs, Modales.
- `forms/`: Elementos de formulario reutilizables.
- `feedback/`: Spinners, Alerts, Toasts.

## Capa de Presentación

Sigue el principio de componentes "limpios" que reciben datos vía props.
