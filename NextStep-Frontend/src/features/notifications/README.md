# Feature: Notifications

Alertas internas del sistema (Campana de notificaciones).

## Patrones de Diseño

- **Observer Pattern**: El componente UI reacciona automáticamente a eventos del servidor o del sistema.

## Responsabilidades (RFFM-04)

- Contador de alertas no leídas.
- Notificaciones de mensajes, verificado, y aplicaciones.
